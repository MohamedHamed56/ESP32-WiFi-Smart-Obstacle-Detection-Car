# ESP32-WiFi-Smart-Obstacle-Detection-Car
WiFi-controlled robotic car using ESP32 Access Point mode, web joystick control, HC-SR04 obstacle detection, L298N motor driver, and buzzer-based collision warning system.

## Overview

This project implements a WiFi-controlled robotic car using an ESP32 microcontroller operating in Access Point (AP) mode.

The system provides real-time movement control through a web-based joystick interface while continuously monitoring obstacles using an HC-SR04 ultrasonic sensor.

When an object is detected within 15 cm, the car automatically stops, blocks forward motion, and activates a buzzer warning.
